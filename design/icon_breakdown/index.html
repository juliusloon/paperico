4 · Affinity 重建步骤

  1. 新建 1254 × 1254 文档（或任意尺寸后按比例换算）。
  2. 最快路径：直接 文件 → 打开 本目录的 00_full-icon.svg，所有描边、圆头端帽、圆环都会以可编辑矢量进入，逐层改色即可。
  3. 手动重建：
    • 节点环：椭圆工具按住 ⇧ 画 176px 正圆 → 描边 46、无填充（或画外圆 88 + 内圆 42 布尔减）。
    • 横条/竖线：钢笔或线条工具画直线 → 描边 88 / 42 → 端点样式选「圆头端帽」。
    • 大括号弧线：钢笔在 (835.7, 324) 和 (794.6, 775) 之间画弧；也可画一个 400 × 480 的椭圆，取右侧弧段后与两条横条「合并」并修剪多余部分。
  4. 图层顺序：竖连接线在最底 → 横条/括号 → 节点环最顶（连接线两端被节点环盖住）。
