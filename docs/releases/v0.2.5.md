# Paperico v0.2.5

发布日期：2026-10-03。App build 7。需要 Apple Silicon Mac 和 macOS 26 或更高版本。

## 更新

- 应用图标替换为新的 Icon Composer 图标。
- 左下角悬浮导航使用新的单色 Paperico 标志，图标采用主题强调色，去除圆形底色并放大。
- 同步当前原生论文库、阅读器、对话、设置与离线公式渲染实现；此前的详细更新见 v0.2.1–v0.2.4 发布说明。
- 正式 DMG 使用干净的 Release 构建，并在打包前检查应用图标名称和编译资源。

## 安装

下载 `Paperico-0.2.5.dmg`，将 Paperico 拖入 Applications 并替换旧版。
此包未使用 Developer ID 签名或 Apple 公证。

## 验证

- 72 项原生核心测试、15 项离线阅读器测试、开发工具测试通过。
- Markdown 流式渲染完成 423 个快照，覆盖 3 种面板宽度。
- 后端 76 项测试与 7 项子测试、Ruff 和 14 个 API schema 合同检查通过。
- 干净 Release 构建通过；DMG 校验与应用临时签名校验通过。
- 挂载 DMG 后导出并查看 `paperico.icns`，确认是新图标，且与已验证的开发构建图标 SHA-256 一致。
