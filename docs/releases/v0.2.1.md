# Paperico v0.2.1

日期：2026-10-01 · App build 3 · macOS 26+。

本次更新修复页面布局、侧栏动画与 PDF 导入，保留已有面板样式。

## 界面

- 顶部安全留白从 58pt 调整为 30pt，比原有紧凑布局多留 8pt。
- 侧栏收起时，消失的文字与按钮不再执行滞后的淡出，内容限制在面板边界内。
- 首页顶部、指标、最近阅读与工作流使用同一内容宽度，最大 1240pt。
- 桌面首页的 RECENT 与 WORKFLOW 卡片等高，装饰图的虚线竖线已删除。
- 窄窗口的工作台导航固定左下，取消原来的 56pt 顶部导航占位。
- 论文库和方法索引使用统一抽屉，从窗口左侧外部向右滑入，关闭时滑回。
- 阅读器窄窗口保留逻辑链／正文／对话分段栏，工作台导航移到左下。

## 导入与启动

- PDF 文件选择器由活动的上传弹窗呈现，修复点击后无法打开系统文件窗口。
- 移除选择 PDF 按钮的系统焦点大边框；上传中避免重复选择或关闭弹窗。
- 未配置解析服务时可先导入，使用中性说明；仅实际选择或导入失败显示错误。
- 批量导入保留逐文件错误反馈，取消文件选择不视为失败。
- 钥匙串读取改为后台操作，界面使用内存中的凭据快照。启动自动读取不弹出
  授权请求；需要访问已保存凭据时，在设置页点击「读取已保存凭据」。
- 凭据保存完成后，之前未结束的读取不会覆盖新凭据。

Apple 说明同步的钥匙串查询会阻塞调用线程，因此不应在界面主线程执行。
参见 [SecItemCopyMatching](https://developer.apple.com/documentation/security/secitemcopymatching(_:_:))。
