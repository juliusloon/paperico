# Paperico v1.3.0

发布日期：2026-10-21。App build 13。基线：1.2.0（App build 12）。需要 Apple Silicon Mac 和 macOS 15 或更高版本。

本版统一论文库、方法索引、阅读器、设置及弹窗的视觉规格，改善窄窗口排版、文字可读性与键盘操作体验。

## 视觉与交互

- 统一工具栏图标、按钮尺寸、弹窗标题、表单、间距和错误颜色；主操作按钮根据强调色选择对比度更高的文字颜色。
- 论文库与方法索引的加载占位跟随实际网格排列；方法卡补齐悬停反馈，排序按钮和面板层次与论文库保持一致。
- 扩大窄窗口中的论文信息与对话抽屉，避免内容被过度压缩；元数据、Zotero 导入和引用来源弹窗根据窗口宽度调整，长标题与正文可以滚动查看。
- 提升分组计数、阅读错误提示与附加证据的可读性，扩大移除证据按钮的点击区域；首页正确显示论文失败状态。
- 恢复导航和自绘控件的键盘焦点，补充阅读模式、进度和缩放按钮的辅助功能信息；按钮按压及阅读进度动画遵循“减少动态效果”设置。

## 修复

- AI 模型设置页的论文库引用说明、工具调用状态和输出预算统一纳入玻璃说明框，保持一致的字号、间距与自适应换行。
- macOS 15 回退材质保留控件强调色；开启“减少透明度”时，玻璃表面使用不透明主题背景。
- 外观设置说明与实际行为一致：主题、强调色和正文字号保存后生效，透明度即时生效。

## 安装与升级

- 下载 `Paperico-1.3.0.dmg`，将 Paperico 拖入“应用程序”并替换旧版本；附带 `.sha256` 校验文件。
- 从 1.2.0 升级无需迁移论文库；本版不修改索引 schema、论文、笔记、对话或模型配置格式。
- DMG 使用 ad-hoc 签名，保留 App Sandbox 及网络权限；未使用 Developer ID 签名，未经过 Apple 公证。
