# Paperico v0.2.3

发布日期：2026-10-01。App build 5。

## 正文阅读器修复

1. 恢复原网页的 Charter / Iowan 英文字体与中文宋体，默认正文 18px、译文 17px，
   英文行高 1.78、中文行高 1.72；保留字号调节和双语段落间距。
2. `<sup>` / `<sub>` 显示为上标和下标。行内数学、独立公式、分式、对齐环境与公式编号
   由随 App 打包的 KaTeX / mhchem 与本地字体渲染，不产生模型请求。
3. 逻辑链标题、叙述角色和方法标签完整换行，取消截断与虚线；紧凑目录同步修复。
4. 阅读器从窗口顶部布局，不再叠加其他页面的红绿灯留白；标题区只保留工具栏所需间距。
5. 信息与对话卡片的标题、主体使用统一底色。
6. 两张卡片悬浮在与正文一致的背景上。可用宽度不足时自动隐藏，放宽后恢复；隐藏时
   右下按钮可打开信息与对话，900pt 以下沿用正文 / 逻辑链 / 对话标签。
7. 原生分隔柄使用屏幕坐标跟随鼠标；拖动不施加动画、不逐帧写入偏好，松手后保存宽度。

正文渲染集中到单个离线文档组件，缩放与侧栏调整重排现有内容。移除旧的未使用正文
BlockRenderer，原生路由、论文库、处理管线、PDFKit、对话和笔记继续沿用既有 Store。
源码与固定依赖见 [reader-renderer](../../macos/reader-renderer/README.md)。

## 验证

- 原生核心 40 项测试通过；新增正文渲染 8 项测试通过，覆盖上标/下标、行内与独立数学、
  TeX 分隔符、化学式，以及原始 HTML / 外部图片 / 链接处理。
- 使用已有测试论文验证：247 个节点、24 张本地图表、16 个独立公式；16 个公式均无
  KaTeX 解析错误。实际界面确认分式、上下标和公式编号显示正常。
- 保存的问答“证据 0009”能定位并短暂高亮对应摘要；不重新调用模型或 MinerU。
- 实际拖动：横移 120px 时卡片边界移动 120px；窗口收窄到约 960pt 时隐藏右侧卡片，
  可通过右下按钮打开信息与对话；放宽后两张卡片恢复。
- 与 v0.2.2 验证结果比较，测试 PDF、段落、实体、对话、笔记五个数据文件 SHA-256
  全部一致。数据和上一版的单次全文分析结果完整保留。
- Release 构建与 DMG 打包成功。本机安装版本、签名和安装包校验信息记录在本地
  `macos/build/validation/`，该目录不包含在公共源码中。

这些验证覆盖本次正文与布局改动；未做不同硬件上的帧率基准，也未重复付费解析。

安装包：`macos/build/Paperico-0.2.3.dmg`。本地构建使用临时签名，正式分发仍需要
Developer ID 签名与公证。
