# Paperico v0.3.0

发布日期：2026-10-04。App build 8。需要 Apple Silicon Mac 和 macOS 26 或更高版本。

## 更新

- 新增 App 内嵌的 localhost MCP 服务：10 个只读工具，读取论文元数据、双语正文块、
  图像、方法索引和已有笔记，并提供论文 metadata / blocks / chat / notes 资源。
- 在「设置 → MCP 连接」开启服务，复制 Claude Code、Cursor 或 VS Code 配置。
  默认关闭；使用独立 Keychain Token，可更换 Token 撤销旧连接。读取不会调用付费 API
  或更新论文的最近打开时间。App 必须保持运行；完整 stdio 代理与动作工具尚待后续版本。
- 校验 Bearer Token、Host 和 Origin，限制请求大小与并发连接；回收站论文和越界图像
  不向 MCP 客户端开放。详见 [MCP 连接说明](../mcp.md)。
- MinerU 云任务保存提交断点，继续处理复用已提交任务；云端排队不占用上传许可，
  任务面板显示排队、页码进度和 trace ID；重新解析 PDF 始终提交新任务。
- 回收站新增逐篇确认后的永久删除，删除论文及对应文件；失败步骤保留记录以便重试。
- 处理任务和回收站使用工作台内浮层；改善长设置表单的底部操作布局。
- 更新中英文 README 的差异说明与流程图，新增 macOS 逐文件架构文档。
- 发布包保留 App Sandbox 和 MCP server entitlement；发布工作流先执行回归测试。

## 安装与升级

下载 `Paperico-0.3.0.dmg`，将 Paperico 拖入 Applications 并替换旧版。
本次提供 ad-hoc 签名，未使用 Developer ID 或 Apple 公证。
原生论文库格式兼容；更新前可备份完整沙盒数据目录。旧后端 SQLite 库仍没有自动迁移。
MCP 客户端可能把读取内容发给它配置的模型服务，请只连接你信任的客户端。

## 验证

- 81 项原生核心测试和 5 项 MCP 集成测试，包含真实 loopback HTTP、官方 SDK 客户端
  互通、并发请求、Token 撤销、资源/图像读取及读取不写索引。
- 开发工具回归测试；退役后端快照不存在时跳过其单独契约检查，合约检查器自身测试保留。
- 离线阅读器测试与生成资源检查、Markdown 流式渲染冒烟检查。
- 干净 Release 构建、DMG 完整性、应用签名、版本号与 Sandbox / MCP entitlement 检查。
