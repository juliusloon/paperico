# Paperico v0.2.0

日期：2026-10-01 · App build 2 · 当前构建要求 macOS 26+ / Xcode 26+。

这是一次原生架构与可靠性更新。在已有原生迁移和 Liquid Glass 界面工作的基础上，
补齐存储、任务、恢复与验证机制，把仓库的运行入口统一到 macOS App。

## 使用上的变化

- App 独立管理本地论文库、处理任务、对话与笔记，无需先运行 Python 服务。
- PDF 可以在未配置 AI 时先导入。配置就绪后，从论文库的「处理任务」开始解析。
- 「处理任务」集中展示待处理和失败论文，可停止、重试或仅重新翻译已有段落。
- 删除改为移入「回收站」，恢复时保留 PDF、图表、解析结果、对话与笔记。
- 批量导入逐个处理文件，单个失败不阻止后续导入，错误按文件名列出。
- ⌘1 首页、⌘2 论文库、⌘3 方法索引；⌘, 打开原生设置窗口。

## 修复

- 修复启动时 `EnvironmentValues.services` 默认 nil 强制解包导致的 SIGTRAP。
- 修复损坏索引被当作空库、IO 失败未报告和并发会话保存丢失更新。
- 修复取消排队任务和立即重试时的生命周期冲突；重新启动显示可重试的中断状态。
- 修复论文间切换时的对话状态污染，使用磁盘中的实际消息 ID 生成笔记。
- 使用本地 ImageIO 读取图表，替换沿用 HTTP 机制的 AsyncImage；图片有明确失败状态。
- 修复无效服务地址可能触发的强制解包，钥匙串保存失败会反馈到设置页。
- 模型输出上限、对话 streaming 设置实际生效；兼容部分端点的 token 字段与温度限制。
- ZIP 解包增加路径、符号链接、截断、大小和 CRC32 检查。
- 修复性能追踪循环阻塞阅读器状态轮询，以及后台刷新更新最近打开时间的问题。

## 开发与仓库整理

- App 生命周期、服务注入和路由分文件；设置、项目、论文、阅读、对话 Store 分文件。
- 增加版本化 LibraryIndex、严格 LibraryFiles、可取消 JobGate 和独立核心测试包。
- `script/build_and_run.sh` 统一构建与运行，Codex Run 按钮复用同一入口。
- `script/check.sh` 统一原生检查；`--with-backend` 加跑兼容后端检查。
- README 中英文同步更新，提供仓库地图、数据位置、隐私边界和旧后端升级说明。
- CI 加入核心测试，App 与 DMG workflow 使用 macos-26 runner。

## 升级与数据

原生迁移期间创建的无版本 JSON 索引可继续读取。损坏数据或更新版本的索引不会被覆盖。
Python 后端的 SQLite 数据库与 API Key 仍独立存在，当前不会自动转换到原生论文库。
保留旧数据；备份原生库时复制整个 Application Support/Paperico 目录。

回收站不自动清空。恢复功能保留数据，持续存放也会持续占用磁盘空间。

```bash
./script/build_and_run.sh --verify
./script/check.sh --with-backend
./macos/scripts/make_dmg.sh CODE_SIGN_STYLE=Manual CODE_SIGN_IDENTITY=- DEVELOPMENT_TEAM=
```
