# Paperico v1.0.1

发布日期：2026-10-05。App build 10。需要 Apple Silicon Mac 和 macOS 26 或更高版本。

## 修复与改进

- PDF 阅读区在正文拖选期间隔离窗口背景拖动，避免选择 PDF 内容时带动整个窗口。
- 论文库、方法类别和设置页标题统一为 24；前两页标题略向右缩进，设置页标题缩小。
  处理任务的重试菜单与打开、停止按钮共用液态玻璃样式。
- 正文范围识别支持 References 之后重新出现的 Methods、Results、附录与扩展图表，
  保留这些章节及图注的翻译和逻辑链，同时继续排除参考文献、出版信息与 Reporting Summary。
- 长论文按原始节点和文本量分段翻译，完成后再结合全文生成总结与方法索引，减少漏节点、
  译文错位与输出截断。严格校验稳定编号、原文开头、译文完整性与方法证据。
- 默认输出上限提高为 65,536；按请求内容分配输出预算，论文分析关闭 Qwen3.5 思考模式，
  避免思考与正文争用输出容量。移除强制 JSON 格式参数，并检测连续空白和重复方法输出。
- 每个请求只生成一次，失败保留响应，不自动重试。手动继续中断的长文任务可复用已完整
  校验的分段；完整结果仍可通过「恢复上次返回结果（不调用模型）」在本地恢复。

## 安装与升级

下载 `Paperico-1.0.1.dmg`，将 Paperico 拖入 Applications 并替换旧版。
本次提供 ad-hoc 签名，未使用 Developer ID 或 Apple 公证。
原生论文库格式兼容，保留现有 PDF、笔记、对话与方法分组。
新的输出上限默认值适用于新配置；已有配置保留用户设置，可在设置页自行调整。

- 133 项 Swift 回归测试通过，覆盖正文范围、节点与原文校验、分段检查点恢复，以及核心
  持久化、方法索引和 MCP 集成。
- 开发脚本测试通过；Markdown 渲染检查通过，覆盖 3 种面板宽度的 423 个流式快照。
- 三篇问题文献的全部节点与已保存结果通过完整性校验。
- Release 构建、应用版本与构建号、签名、Sandbox/MCP 权限和 DMG 完整性检查通过。
- PDF 拖选的实机交互未能由自动化工具验证，需实际拖选确认。
