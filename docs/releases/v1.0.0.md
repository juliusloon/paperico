# Paperico v1.0.0

发布日期：2026-10-05。App build 9。需要 Apple Silicon Mac 和 macOS 26 或更高版本。

## 更新

- 方法索引引入持久分组：全部 8 个预设分组始终可见（包括空分组）；支持新建、改名、删除
  和把条目拖入其他分组，分组名称不能重复；删除分组会删除其中所有索引条目，并在确认框中
  明确说明。分组与条目移动保存在本机论文库，论文原文和解析证据仍然保留。
- 新论文分析接收全部当前方法分组与已有方法清单：模型建议只能使用有效分组；已有条目沿用
  其稳定 ID 和用户编辑后的名称、分组，类别相同不会自动合并。手工整理越多的库，新论文的
  方法识别越贴合自己的用法。
- 分析边界收紧：论文作者/出版信息与参考文献不进入翻译与逻辑链请求（原始块仍保留）；
  保守识别无标准标题的文献段落；正文缺块、乱序或缺译文会使分析失败，而不是返回不完整结果。
- 钥匙串凭据统一保存与串行读取，AI、PDF 解析和 MCP 共享本次运行的授权结果；取消授权
  不再继续弹出其他凭据窗口。已有密钥显示「待解锁」，不误报为未配置。旧条目安全迁移，
  失败保留原值；首次迁移及签名变化的系统授权次数仍由 macOS 决定。
- 「设置 → 关于」显示应用版本、构建号、作者、MIT 许可与项目链接，提供正式版本检查和
  自动检查开关。自动检查每天最多一次，发现新版本后提醒并打开发布页下载；检查失败不会
  打断阅读。应用菜单提供「关于 Paperico」与「检查更新」，均复用工作台内的关于页。
- 界面统一：论文与方法的分组控件、拖拽反馈共用同一套圆角液态玻璃样式（拖拽预览锚定
  指针，目标分组显示加号）；界面使用系统字体，论文正文排版保留衬线；文章标题只显示一次
  （衬线加粗中英对照），保留原始块与证据链接；逻辑链与节点笔记编辑框复用原生 Liquid Glass
  输入表面与保存/取消按钮，直接拖动右下角调节大小；分割条接管鼠标拖动，避免带动窗口；
  行内编辑统一，卡片与分组操作移入右键菜单；底部导航使用随强调色变化的矢量 Paperico 字标。
- 历史对话支持右键改名与删除：改名使用同字号的行内编辑框，删除前确认清除全部消息；
  已导出的笔记保留，操作只影响所选论文的目标会话。
- 编辑时沿用显示状态的字号；论文、方法、分组及历史对话的名称编辑与确认/取消位于同一行，动作靠右。
  逻辑链编辑和笔记入口改为原生玻璃按钮，笔记使用笔记图标；笔记编辑支持 ⌘B/⌘I/⌘H
  切换加粗、斜体、高亮，格式与文本一并保存。逻辑链栏的进出匹配右侧栏的 280ms 动画。
- 对话中的原文证据编号在原位显示为可点击的玻璃按钮，随段落换行；正文、列表、引用、
  表格和流式回答均使用同一机制。代码和无效引用保持普通文字，复制时保留完整证据编号。

## 安装与升级

下载 `Paperico-1.0.0.dmg`，将 Paperico 拖入 Applications 并替换旧版。
本次提供 ad-hoc 签名，未使用 Developer ID 或 Apple 公证。
原生论文库格式兼容；更新前可备份完整沙盒数据目录。旧后端 SQLite 库仍没有自动迁移。

## 验证

- 108 项原生核心测试，覆盖分析边界收紧（作者/文献段排除、缺译文拒绝）、方法分组的
  合并与身份保持，以及库、管线、对话改名/删除、证据编号、笔记格式与归档回归。
- 5 项 MCP 集成测试，使用真实 loopback HTTP 与官方 Swift SDK 客户端互通。
- 24 项离线阅读器测试与生成资源检查、Markdown 流式渲染冒烟检查。
- 干净 Release 构建、DMG 完整性、应用签名与版本号检查。
