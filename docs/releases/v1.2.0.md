# Paperico v1.2.0

发布日期：2026-10-08。App build 12。基线：1.1.0（App build 11）。需要 Apple Silicon Mac 和 macOS 15 或更高版本（此前要求 macOS 26，本版起下调）。

1.2.0 的主线是**跨论文问答**：你的整个论文库成为对话上下文——模型可以按需检索、读取库内其他论文来回答宽泛问题，并给出可点击跳回原文的证据来源。同时补齐元数据工作流（旧论文回填、手改保护、Zotero 导入）并把最低系统版本降到 macOS 15。

## 新增

- **可选论文库问答（Library-aware Chat）**：默认关闭，在设置中开启后，对话不再局限于当前论文。
  - 支持工具调用的模型走 **agent 路径**：只读工具集（`search_library` / `get_paper` / `search_methods` 等）按需检索与读取库内论文，**有界执行**——默认最多 3 轮工具调用、总计 8 次，达到上限后强制基于已收集证据收束回答。工具走进程内调用，不经 MCP loopback，因此不要求开启 MCP、也不暴露 MCP token；工具不改变阅读状态、不触发解析管线、不访问外部网络。
  - 不支持工具的服务自动走 **deterministic fallback**：本地关键词检索 Top-K 论文、注入压缩 brief、一次问答生成。能力探测只在设置页「测试连接」时进行，对话中不重复探测。
  - 对话 UI 区分**论文 / 方法 / 跨论文**三类证据来源，显示本轮查阅论文数与库内查询数；来源卡可打开对应论文并返回原会话。
- **Zotero 导入**：支持 Zotero「导出集合 → BibTeX + Export Files」产出的文件夹——`.bib` 与附件 PDF 按路径/文件名配对，bib 元数据作为权威值预填（记为 manual，自动识别不会覆盖），导入摘要逐条列出已导入 / 无元数据 / 重复跳过 / 未配对。兼容 Zotero 7–10 导出的 bib 变体。
- **旧论文元数据识别**：论文库支持对单篇或批量旧论文执行「识别元数据」——从原文识别 DOI / arXiv 并回填作者、年份、期刊；manual 论文跳过并提示原因；网络失败静默降级。
- **元数据编辑**：MetaCard 新增标题 / 作者 / 年份 / 期刊 / DOI / arXiv 编辑入口，编辑后记为 manual；MetaCard 同时显示标识符与元数据来源。
- **引用质量验收**（发布 harness，opt-in）：`PAPERICO_E2E_QUESTIONS` 激活后对人工题库全量跑问答，输出引用命中率、伪来源数、工具预算等指标，低于阈值直接 FAIL；伪引用 > 0 即 FAIL。

## 变更

- **最低系统版本降为 macOS 15**：部署目标从 26 下调；26 专属的液态玻璃 API 收敛到 GlassKit 统一封装（`GlassGroup` / `liquidScrollEdge`），旧系统自动落到系统材质回退，macOS 26+ 观感不变。部署目标即回归门禁——引入未加门槛的 26 专属 API 会直接编译失败。
- 重新分析保留手动改过的标题（`meta_source = manual` 的标题不再被 LLM 标题覆盖）。
- 对话系统 prompt 补齐作者、年份、期刊、DOI，与笔记合成端对齐。
- MCP `get_paper` 对元数据回填后的论文返回 doi / authors / year（随 `PaperListItem` 契约带出，新增测试锁定）。

## 修复

- **修复宽泛问题几乎必现的「已停止生成」空回答**：发送 / 停止双态按钮（或 Esc）在流式刚开始的数百毫秒内被二次触发时，会立即取消刚建立的请求。`stopGenerating` 现带 1 秒武装期，期内重复触发被忽略；真正的停止意图在武装期后照常生效。
- LLM 请求链路补充 debug 级诊断日志（请求发出、响应状态码、收包字节、取消 / 失败原因，子系统 `com.paperico.app`），诊断客户端取消类问题时不再丢失响应体证据。

## 开发者可见

- 全量测试 233 项 0 失败（2 项 opt-in 跳过），含 tool-call SSE / agent loop mock 与新增 `LibraryAutomationMetadataTests`。
- 新增 `macos/scripts/e2e/citations.manifest.json`（schema 注释 + 样例；PDF 本体因版权不入库，运行时经 `PAPERICO_E2E_PDF_DIR` 提供）。

## 安装与升级

- 数据目录 `Application Support/Paperico/` 结构不变：论文库、PDF、笔记、对话、方法分组全部保留。
- 从 1.1.0 升级无需任何手工操作；索引 schema 无变化。
- 论文库问答默认关闭；开启前请在设置页「测试连接」确认当前模型对工具调用的支持情况。
